# Canonical Model Design

## Shared Fields
Every canonical model includes:
- unique ID
- source system
- vendor
- timestamp
- version
- correlation ID
- tenant ID
- labels
- tags
- metadata
- status
- created time
- updated time
- confidence
- severity when applicable
- business priority

## Domain Grouping
Canonical models are grouped by enterprise concern:
- infrastructure
- monitoring
- topology
- operations
- business
- ai
- memory
- governance
- security
- workflow
- events
